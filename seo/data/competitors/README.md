# Competitor Data

Place competitor exports and manual SERP reviews in this folder.

Recommended files:

- `competitor-pages.csv`
- `competitor-backlinks.csv`
- `serp-custom-software-usa.csv`
- `serp-hire-developers-usa.csv`
- `serp-web-app-development.csv`
- `serp-mobile-app-development.csv`

Use the columns in `competitor-pages-template.csv` for manual reviews.
